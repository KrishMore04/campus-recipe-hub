# Campus Recipe Hub

Campus Recipe Hub is a dynamic recipe management web application developed as a Cloud Computing and DevOps project.

## Features

- View recipes dynamically from server data
- Search recipes by name, category, or ingredients
- Add new recipes using a form
- Input validation for recipe data
- JSON API for recipe operations

- ## Technologies Used

- Node.js
- Express.js
- HTML
- CSS
- JavaScript
- Git and GitHub
- GitHub Actions
- Docker
- Render

## Application Routes

- `GET /` — Main recipe website
- `GET /api/recipes` — Returns recipes as JSON
- `POST /api/recipes` — Adds a new recipe
- `GET /health` — Application health check
- `GET /api/commit` — Returns the running commit ID
